# MeowX001-GTA_VC-Checkpoint-Cherlie-Updated-Time
In GTA VC DE and Android, the mission checkpoint cherlie gives you additional 30 seconds to complete all the 6 levels but in the original the time was 30 seconds less, making the last attempt extremely hard and impossible to complete.
I made a simple CLEO script which adds additional 30 seconds on each attempts, making the mission sightly bearable and relaxing.
